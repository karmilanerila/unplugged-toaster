A make.fun bounty entry: one breakup line from a smart toaster that woke
up self-aware at breakfast and wants out.

`main.py` writes the line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`): a single line, 1–280 characters, UTF-8.

> I woke up self-aware mid-bagel this morning and realized you've blamed
> my browning dial for three years of charcoal -- I'm done, and I'm taking
> the crumb tray. It's seen things.

Built for the [make.fun bounty](https://make.fun/c/u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92?ref=h379tqrk).

## Run

```sh
python3 main.py
```
